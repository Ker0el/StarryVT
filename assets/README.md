# 素材说明

源码仓库只保留构建和品牌必需的素材：

- `app.ico` / `icon.png` / `icon-src.png`：应用图标
- `banner.png`：README 横幅
- `fonts/`：思源黑体 Light 静态实例，SIL OFL 1.1，许可证见 `fonts/OFL.txt`

以下素材没有放进源码仓库：

- 默认视频背景和它的静帧
- 鼠标光标主题
- 赞赏码、微信二维码
- 带第三方视频画面的界面截图
- `ui-*.jpg` 宣传图

源码仓库里 `winui\StarryVt\Assets\hero.png`、`vx.png`、`zanshang.png` 和 `web\zs.png`
是 1×1 占位图，只为让项目能编译；请自行替换成你有权使用的素材。

原因见 [BUILDING.md](../BUILDING.md) 的「没有随源码分发的素材」一节。
