**引擎装不上时不再误报「下载被限流」**
- 引擎的 Python 组件导入就崩（DLL 加载失败）时当场认出来，自动重建运行环境再试；仍失败会直说是安全软件拦了 DLL，不再劝人「等一小时、反复点」。
- 装引擎改用 uv 托管的 Python，不再回落到机器上那份没测过的解释器。
- 诊断报告新增「引擎 Python 环境」：解释器版本、pyd 校验值、python312 / vcruntime 版本。

**本地语音克隆在中文目录下自动修**
- 运行环境的启动器找不到解释器（`No Python at` / 退出码 103）时自动重建；uv 的 Python 不再放进中文路径。

**更新与重装**
- 更新后会核对程序文件有没有真的换掉（装前/装后尺寸+时间都记进日志），没换掉会在「环境自检」里说明。
- 安装包不再沿用注册表里那个已经不存在的旧安装路径，重装不会装回被删掉的目录。
