## 引擎与编辑器

- Unreal Engine|虚幻引擎|UE、UE5、UE4|引擎全名；ASR 常听成 Unreal / Unrull / Anreal，注意是 Unreal Engine
- Blueprint|蓝图|蓝图系统|可视化脚本系统，官方中文名「蓝图」；ASR 常听成 Blueprin / Blueprint
- Nanite|Nanite||虚拟几何体系统，官方文档保留英文，不要译成「纳米石」
- Lumen|Lumen||全局光照与反射系统，保留英文
- Niagara|Niagara||粒子与特效系统，保留英文；ASR 常听成 Niagra / Niagara
- Sequencer|Sequencer|定序器|过场与镜头动画工具，官方界面保留英文 Sequencer
- MetaHuman|MetaHuman|数字人|数字人创建工具，保留英文
- Chaos|Chaos|混沌物理|物理与破坏系统，保留英文
- World Partition|世界分区|世界分区系统|开放世界的流式加载系统，官方中文名「世界分区」
- Control Rig|Control Rig|控制绑定|骨骼绑定与动画工具，官方界面保留英文
- PCG|PCG|程序化内容生成|Procedural Content Generation，程序化生成框架
- UMG|UMG|虚幻动态UI|Unreal Motion Graphics，UI 编辑系统
- Metasound|MetaSound|元声音|新一代音频合成系统，保留英文
- Actor|Actor|演员、行动者|场景里的基础对象，保留英文，不要译成「演员」
- Pawn|Pawn|棋子|可被控制的 Actor，保留英文
- Character|角色|人物|可移动的 Pawn，中文界面叫「角色」
- Level|关卡|场景|官方中文名「关卡」，不要译成「等级」
- Static Mesh|静态网格体|静模、静态模型|官方中文名「静态网格体」
- Skeletal Mesh|骨骼网格体|骨骼模型|官方中文名「骨骼网格体」
- Material|材质||官方中文名「材质」
- Material Instance|材质实例||官方中文名「材质实例」
- Texture|纹理|贴图|官方界面叫「纹理」，社区也说贴图
- Landscape|景观|地形|地形系统，官方中文名「景观」
- Post Process|后处理|后期处理|后处理体积与后处理材质
- Content Browser|内容浏览器||资源面板，官方中文名
- Outliner|大纲|世界大纲视图|场景层级面板，官方中文名「大纲」
- Viewport|视口|视图|官方中文名「视口」
- Game Mode|游戏模式||一局游戏的规则类，官方中文名
- Widget Blueprint|控件蓝图|UI 蓝图|UMG 的编辑对象，官方中文名「控件蓝图」
- Animation Blueprint|动画蓝图|动画蓝图 AnimBP|驱动角色动画的蓝图
- Blend Space|混合空间||按参数混合动画，官方中文名
- Animation Montage|动画蒙太奇|蒙太奇|拼接触发式动画，官方中文名「动画蒙太奇」
- Spline|样条线|样条|官方中文名「样条线」
- Event Graph|事件图表|事件图|蓝图里连线的地方，官方中文名「事件图表」
- Data Table|数据表||官方中文名「数据表」
- LOD|LOD|细节层级|Level of Detail，保留英文
- C++|C++|CPP、C 加加|ASR 常听成 C / C+ / C 语言，写全 C++
